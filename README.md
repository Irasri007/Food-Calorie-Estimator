# Food-Calorie-Estimator
An intelligent AI-powered web application that analyzes food images, recognizes the dish, and instantly estimates calorie counts along with key macro-nutrient values such as carbohydrates, proteins, and fats. It also checks user allergies or medications and offers safe, personalized alternative food suggestions
# 🚀 Features

🔍 AI Food Recognition

Upload image or capture using camera

Identifies the food using ML model (CNN / placeholder)

# 🍽️ Calorie & Nutrition Estimation

Calories

Carbohydrates

Proteins

Fats

Portion-size slider with real-time recalculation

# ❤️ Health-Aware Alternatives

Takes user allergies & medications during login

Warns if detected food is unsafe

Suggests safe and healthy substitutes

# 🗂️ User Dashboard

Stores food history

Shows previous calorie results

Firebase integration (optional)

🎨 Streamlit UI

Clean gradient theme

Responsive layout

Works on mobile & desktop
